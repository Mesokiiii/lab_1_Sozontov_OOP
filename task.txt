Лабораторная работа 1.
Цель лабораторной работы – изучить основные элементы подсистемы WPF для построения интерфейса приложения.
Задачи. 
1) Разработать приложение, удовлетворяющее нижеуказанным требованиям.
2) Протестировать  работу приложения.
3) По проведенной работе написать отчёт. 

Техническое задание:
1.	 Разработанное приложение должно иметь ряд вкладок (TabControl).
1.1.	Основное. На этой вкладке должны быть размещены:
1.1.1.	Сгруппированные настройки персонализации:
1.1.1.1.	выбор темы приложения из распахиваемого списка(без реализации логики).
1.1.1.2.	выбор языка приложения из распахиваемого списка(без реализации логики).
1.1.2.	Сгруппированные настройки шрифтов:
1.1.2.1.	Выбор шрифта в приложении из распахиваемого списка. (без реализации логики).
1.1.2.2.	Выбор размера шрифта приложения через слайдер. (без реализации логики).
1.2.	Цветовая палитра. На этой вкладке должны быть размещены:
1.2.1.	Вывод наименования текущей темы приложения.
1.2.2.	Сгруппированные цвета с цветовым отображением: основной, акцентный. индикаторные (Успех, Ошибка, информация).
1.2.3.	Таблицы с цветовой палитрой оттенков(10) (цвет/rgb код/наименование) для каждого из цветов из пункта выше(п 1.2.2).
1.3.	Элементы управления. 
1.3.1.	На этой вкладке необходимо сгруппировать по распахиваемым контейнерам следующие компоненты и их состояния(для каждого цветового отображения из п 1.2.2):
1.3.1.1.	Кнопки(обычные, пиктограммы, переключатели). Пример размещения элементов:
  
1.3.1.2.	ListBox, Combobox, TextBox, PasswordBox, RichTextBox
1.3.1.3.	TextBlock, Label – c заголовками 1-3, обычным тесктом и подписью.
1.3.1.4.	TreeView
1.3.1.5.	DataGrid
1.3.1.6.	ProgressBar
1.3.1.7.	Всплывающие подсказки.
1.3.1.8.	Меню и контекстное меню.
1.4.	Контейнеры компоновки. На этой вкладке показать разницу между контейнерами компоновки на примере окрашенных в тему приложения прямоугольников.


Структура отчёта:
1.	Цели и задачи
2.	Описание приложения. Описание используемых элементов(со скриншотами).
3.	Трудности, с которыми столкнулись в процессе работы
4.	Вывод.
